You are building a **premium Telegram Mini App for Pocket Creator**.

# 4. VISUAL DIRECTION

The dominant visual language should be:

- white background
- near-black typography
- soft light-grey surfaces
- **deep burgundy / wine accents derived from the Pocket Creator logo**
- subtle burgundy gradients
- dark charcoal premium sections
- modern Glass UI elements
- large rounded corners
- soft shadows
- controlled blur
- subtle translucency
- generous whitespace
- premium Apple-like visual quality
- native Telegram Mini App feeling

The interface must remain predominantly light.

Do NOT turn the whole app into a dark theme.

The visual formula should feel approximately like:

**WHITE + CHARCOAL + BURGUNDY + GLASS**

The burgundy should become a recognizable Pocket Creator accent.

---

# 5. BURGUNDY COLOR SYSTEM

Use the actual Pocket Creator logo as the primary reference for the burgundy tone.

Do not invent a completely unrelated red.

Create a restrained brand palette around the logo:

### Primary Burgundy
Use the closest appropriate burgundy from the logo.

### Deep Burgundy
For dark sections, active states and premium surfaces.

### Soft Burgundy
For subtle backgrounds, chips and selected states.

### Burgundy Gradient
Use very subtle gradients such as:
- burgundy → deep burgundy
- burgundy → charcoal
- burgundy → transparent

Avoid loud red gradients.

The burgundy should feel:
- sophisticated
- cinematic
- expensive
- editorial
- modern

NOT:
- gaming
- neon
- cheap
- overly saturated
- childish

Use burgundy strategically:
- primary CTA
- selected navigation state
- small badges
- gradient highlights
- hero lighting
- membership cards
- subtle icons
- active states
- occasional decorative glow

Do not make every element burgundy.

---

# 6. GLASS UI SYSTEM

Introduce a modern **Glass UI** language.

Important: Glass UI should be subtle and functional.

Use:
- translucent white surfaces
- backdrop blur
- low-opacity borders
- soft shadows
- subtle reflections
- background blur
- layered cards
- floating pills
- glass navigation
- glass CTA containers where appropriate

Example visual treatment:

rgba(255,255,255,0.55–0.80)
+
backdrop-filter: blur(...)
+
very subtle 1px translucent border
+
soft shadow

For dark sections, use dark translucent glass rather than pure opaque black wherever appropriate.

The glass effect should be most visible in:
- floating bottom navigation
- hero overlays
- premium membership card
- small floating badges
- modal/sheet components
- selected controls

Do NOT put Glass UI on every card.

Too much glass will destroy the hierarchy.

Use a hierarchy:

1. Flat white background
2. Soft grey cards
3. Premium dark/burgundy cards
4. Glass elements on top of those surfaces
